# xDOMEA UI
This is a conveinient way to generate xdomea 4 0605 with with a gui. It can be used as a blueprint for further processing. 
## build and run
```shell
go build;
./xdomea-ui;
```
will spin up a little server on http://127.0.0.1:8080. You can visit it and create xDomea with you Mouse by dragging the AKTE / VORGANG / DOKUMENT Types and finally clicking on generate.
